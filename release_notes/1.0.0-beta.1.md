## New

- **Zefiro.** Ratatoskr is now Zefiro, an independent fork that no longer merges from Artemis. The app has a new swallow icon (adaptive and themed icons, Android TV / Google TV banner) and a new application id, `dev.kylobyte.zefiro`, so it installs next to the old Ratatoskr. Version numbers start again from 1.0.0.
- **Launch games from ES-DE, Daijisho and Pegasus.** A new PC menu action, *Add games to ES-DE*, writes one entry per host game into a ROMs folder you pick and registers a Zefiro system in ES-DE, with the cached covers. Daijisho and Pegasus launch games the same way.
- **Controllers on the AYN Odin and similar.** Some Android builds re-emit external gamepads through a virtual device with its own vendor id. The controller type is now guessed from the device name when the id is unknown.
- **PyroWave.** The low-latency PyroWave codec decodes and presents natively with Vulkan, as an opt-in setting on a Vibepollo host. PyroWave streams get their own bitrate, are no longer asked for HDR, keep the default wavelet precision on Adreno and show their stats in the overlay and on the companion panel. A crash when leaving a stream is fixed.
- **Reconnect after a network drop.** When the connection to the host goes silent, the stream reconnects on its own, keeping the last frame on screen. The silence timeout defaults to 5 s.
- **Adaptive bitrate and live bitrate.** On a Vibepollo host, the in-game menu changes the bitrate of the running stream, and an adaptive controller can raise and lower it by itself.
- **Video error correction.** A new setting for dynamic FEC, with whole lost FEC blocks counted correctly.
- **Smoother frame pacing.** The frame pacing setting is honoured again, and the renderer follows display refresh rate changes.
- **Keyboard on the PC's text fields.** When the PC focuses a text field, the Android keyboard opens; passwords stay out of its suggestions.
- **Companion panel.** Tap the telemetry strip for the full stream stats. Telemetry views now come from zefiro-telemetry-views, and the host is called Scirocco throughout.

## Notes

- Live bitrate, adaptive bitrate and PyroWave need a Vibepollo host; on a stock host nothing changes.
- The app ships in English only.
- Zefiro is a separate app from Ratatoskr: settings are not carried over, and you can uninstall Ratatoskr once you have switched.

**Full install:** grab `zefiro-nonRoot_game-release.apk` below, or use Obtainium.
